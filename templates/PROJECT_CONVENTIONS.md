# 프로젝트 컨벤션

이 문서는 `ios-dev-harness` 플러그인의 에이전트(ios-developer, ios-unit-tester, ios-qa 등)가 **최우선으로** 따르는 프로젝트 고유 규칙입니다. 플러그인 자체는 특정 아키텍처/UI 프레임워크에 종속되지 않도록 설계되어 있고, 실제 프로젝트마다 다른 부분(MVVM vs TCA, SwiftUI vs UIKit, 모듈화 방식 등)은 이 문서를 통해 전달됩니다.

## 사용법

아래 항목을 이 프로젝트에 맞게 채운 뒤, **이 파일 내용을 프로젝트 루트의 `CLAUDE.md`에 `## 프로젝트 컨벤션` 섹션으로 붙여넣으세요.** 항목을 비워두면 에이전트가 기존 코드를 탐색해 추론하고, 그마저 없는 완전 신규 프로젝트라면 합리적 기본값(SwiftUI + MVVM)을 쓰고 그 가정을 결과에 명시합니다.

**이미 아키텍처/컨벤션 문서가 있다면** 아래 항목을 전부 다시 옮겨 적을 필요 없습니다. `CLAUDE.md`의 `## 프로젝트 컨벤션` 섹션에 그 문서 경로만 링크해두면, 에이전트가 알아서 열어 확인합니다:

```markdown
## 프로젝트 컨벤션
아키텍처/컨벤션 문서: `docs/ARCHITECTURE.md` 참조
```

값이 복잡하지 않거나 문서가 여러 곳에 흩어져 있다면, 아래 항목별로 직접 채우는 편이 에이전트가 한 번에 파악하기 쉽습니다.

---

- (예: MVVM / TCA / Clean Architecture / 모듈별 혼용 — 혼용이면 모듈별로 명시)
